# Cuaderno del Tail-sitter

Cuaderno de estudio interactivo (en español) para construir el modelo no lineal 6DOF de un VTOL tail-sitter: marcos de referencia, ecuaciones de Newton y Euler, cinemática con cuaterniones, aerodinámica por strip theory, propulsión (motor, hélice, estela), trim, linealización, control, sensores, mejora de la precisión del modelo y herramientas (MATLAB, Simulink, Python, simuladores).

Abre `index.html` en un navegador, o visita la versión publicada con GitHub Pages.
